# Contributing

Thanks for helping improve Context Bridge.

## Local Checks

```powershell
npm install
npm run verify
```

## Pull Request Expectations

- Keep live-write behavior out of scope unless it has explicit review gates.
- Add or update tests for parser, staging, MCP, or security behavior.
- Do not commit private chat exports, generated staging data, API keys, or local media.
- Keep ChatGPT Apps SDK, Codex plugin, and OpenAI Skills wording precise; they are related but not interchangeable surfaces.
